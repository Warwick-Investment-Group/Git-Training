# Warwick Investment Group: Git Training for Data Science

## Description

This repository serves as a training resource for Warwick Investment Group's Data Science team to learn and master Git version control. Designed specifically for working with data, analytical scripts, and SQL, this hands-on training provides practical exercises and best practices for incorporating version control into your daily workflow.

## Purpose

At Warwick Investment Group, we believe that robust version control is essential for maintaining high-quality, collaborative code that drives our investment decisions. This repository will help you:

- Understand the fundamentals of Git and distributed version control
- Learn Git commands and workflows relevant to data science and analytical work
- Master SQL versioning techniques specific to analytics environments
- Implement best practices for collaborative development
- Troubleshoot common Git issues that arise during data work

## Target Audience

This training is designed for:
- Data professionals new to version control
- SQL developers transitioning to collaborative workflows
- BI specialists working on shared dashboard code
- Data scientists managing analytical code repositories
- Anyone in the Warwick Investment Group looking to improve their Git skills

## What You'll Learn

Through hands-on exercises and practical examples, you'll learn to:
- Set up Git on your development environment
- Clone, branch, commit, and push changes
- Collaborate effectively with team members
- Manage SQL scripts, data pipelines, and analytical code
- Resolve conflicts and troubleshoot common issues
- Implement Git workflows optimized for data science

## Getting Started

1. Clone this repository
2. Follow the installation instructions in the README
3. Complete the exercises in sequential order
4. Refer to the supplementary materials for deep dives on specific topics
